# Frequently Asked Questions (FAQ)

## 1. What is Annu's development process?
Annu follows a structured 4-phase agile delivery cycle:
1. **Discovery & Architecture**: 30-minute discovery call to define exact requirements, data models, API integrations, and milestone timelines.
2. **Interactive Prototype / Wireframe**: Rapid design preview so you can experience the layout and user flow before deep coding.
3. **Core Development & AI Integration**: Frontend engineering, backend logic, AI agent orchestration, and secure database setup.
4. **Testing, Deployment & Handoff**: Thorough testing across devices, deployment to production (Vercel/Supabase/Cloud), and complete source code and documentation transfer.

## 2. Who owns the source code and IP?
Upon final milestone settlement, the client owns 100% of the proprietary source code, database architecture, design assets, and intellectual property. Complete repository transfer is executed via GitHub.

## 3. How do payments and milestone schedules work?
Projects are structured on milestone-based deposits to ensure alignment and accountability:
- 40% initial deposit to begin architecture and development.
- 30% upon milestone preview/demo.
- 30% upon final production deployment and sign-off.
Payment methods accepted include Bank Wire / NEFT / IMPS, UPI, and international payment methods.

## 4. Can Annu build AI agents that connect to our internal databases and CRM?
Yes! Annu builds production-grade agents utilizing function calling, secure webhook triggers, and vector search (RAG) that connect to PostgreSQL, Supabase, HubSpot, Salesforce, Google Sheets, WhatsApp, and Slack.

## 5. What if we need revisions or changes after launch?
All projects include a 14 to 30-day complimentary post-launch support window to fix any bugs, resolve unexpected edge cases, and ensure smooth real-world operation. Ongoing monthly retainer options are also available for continuous feature development.

## 6. How soon can Annu begin work on a new project?
Depending on current pipeline availability, Annu typically kicks off new projects within 2 to 5 business days following requirement alignment and initial deposit.
