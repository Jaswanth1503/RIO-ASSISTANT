# Technologies & Architecture Stack

Annu Jaswanth utilizes modern, industry-standard technologies to ensure high performance, security, and maintainability.

## 1. Programming Languages
- **TypeScript / JavaScript**: Primary stack for full-stack web, asynchronous APIs, Next.js server components, and interactive interfaces.
- **Python**: Core language for AI agent reasoning pipelines, Machine Learning model training, Computer Vision (OpenCV, YOLO), and data processing.
- **Java**: Strong foundation in Object-Oriented Design, data structures, algorithms, and enterprise software patterns.
- **SQL**: Relational database modeling, query optimization, indexing, and transactional integrity.

## 2. Frontend & User Experience
- **Next.js 15 & React 19**: App Router, Server Components (RSC), Server Actions, Streaming SSR, dynamic routing, and fast initial page loads.
- **Tailwind CSS**: Utility-first responsive styling with custom color tokens, smooth dark-mode support, and micro-animations.
- **Shadcn UI & Radix UI**: Accessible, headless, and keyboard-navigable UI primitives (modals, dropdowns, toasts, drawers).
- **Lucide Icons**: Clean, consistent vector iconography.

## 3. Artificial Intelligence & Agent Frameworks
- **Google Gemini (2.5 Flash / Pro)**: High-speed, context-rich reasoning, multimodal input handling, structured JSON generation, and function calling.
- **Whisper (OpenAI)**: Robust speech-to-text transcription with noise resilience across English, Telugu, and Hindi.
- **F5-TTS**: Fast, high-fidelity zero-shot and fine-tuned Text-to-Speech voice cloning.
- **Vapi AI**: Voice telephony infrastructure for low-latency autonomous conversational phone calls.
- **PyTorch & Hugging Face**: Machine learning framework for neural network training, embeddings, and fine-tuning.
- **LangChain / LlamaIndex**: Prompt templates, context window memory buffers, and retrieval-augmented generation (RAG).

## 4. Backend, Database & Infrastructure
- **Supabase**: Managed PostgreSQL database with Row Level Security (RLS), real-time change subscriptions, and secure RESTful endpoints.
- **Resend**: Transactional email delivery with instant delivery rates and React-based email templating.
- **Vercel**: Edge network deployment, serverless lambda functions, automated CI/CD pipelines, and high availability.
- **Docker**: Containerization for reproducible microservice deployment.
